# 第一章探索记录 v1（2026-10-20）

## 本次实现

沿用现有自建统计服务与匿名设备编号；当前是游客模式，不强制微信登录，不采集昵称、手机号或openid。清缓存/换设备会产生新编号，不能据此识别同一自然人。

客户端入口：局外战斗页“冒险记录”。最多保存最近30局，空间不足会缩减；可查看结果、用时、开局等级、击杀、带出与丢失物资，以及所选卡片。记录独立于成长存档，不会因为死亡重置。继续同一局沿用局号与事件序号；旧版进行中的对局只记录更新后的部分，标记partial，不纳入完整开局比例。

## 数据口径

- 结果：通关clear、成功撤离extract、死亡death、主动放弃abandon、未结算active。暂停、切后台、暂存回首页不算死亡或放弃；重新开局会将未结束的上一局标记主动放弃。
- 每局：开局版本、角色、武器永久等级、已选卡片、当前形态、生命、击杀、路线与时间、拾取/带出/丢失材料。
- 房间：到达顺序与时间、访问次数、活动秒数、击杀、累计实际扣血、清理完成。房间时间含走动和战后拾取，不含暂停/选卡/对话，不应解释为纯战斗秒数。
- 卡片：来源、三选一选项、品质、武器、效果、最终选择及刷新事件。进入房间时保存该时刻武器配置。
- 村长：询问弱点、救援、药剂拾取、撞墙、尝试破铃、破铃中断（受伤/窗口关闭/移动或离开范围）、破铃成功、是否未破铃强杀。
- 撤离：首次介绍、半血/危急提醒的时间与场景、当时是否可撤离、后续结局。通过时间线查看提醒后到结局的间隔。
- 日期筛选和网页时间显示均为北京时间（UTC+8）；数据库继续保存UTC。后台按开局版本、开局锄头等级、匿名设备、监控内首次/后续挑战筛选；跨版本续局保持局号，事件currentBuild标记实际运行版本。
- 这些是客户端自报的体验数据，不用于竞技排名或可信资产结算。

## 本地与上传

本机历史、队列、序号保存在kdtl-exploration-v1。每30秒有效进度与关键节点落盘；没有逐帧坐标。单个请求一条事件，成功明确确认run_id+seq后才删除；失败30秒后重试。队列最多100条、最长7天，本地记录与队列合计限制约850KB；超限先丢普通快照。dropped记录丢弃数，不保证无限离线和强杀前最后数秒不丢。

开发工具/体验环境标记测试，后台默认排除。现有手动“排除本机”开关阻止新增上传，但保留本地冒险记录，旧队列可继续发送。reportingEnabled=false时不新增上传、不发送队列。

开发工具：`__GAME__.exploration.status()` 查看pending、acknowledged、error、dropped、localRuns；`__GAME__.exploration.history`查看本机记录。pending=0不能单独证明入库，需有acknowledged或后台记录。
